========================================
Data Import - Operating Unit Integration
========================================

This module integrates Operating Unit support into the Data Import module. It
allows data import documents to be scoped to a specific operating unit, and
restricts access to those documents based on the operating units assigned to
the user.


Work Instruction
================

* `Create Data Import <docs/data_import/index.html>`_
